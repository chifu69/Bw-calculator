# BW & FT Calculator

Mobile-friendly Basis Weight and roll length calculator.

## Publish with GitHub Pages
1. Open **Settings** in the repository.
2. Open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Tap **Save**.

Your site should be: `https://chifu69.github.io/bw-calculator/`
